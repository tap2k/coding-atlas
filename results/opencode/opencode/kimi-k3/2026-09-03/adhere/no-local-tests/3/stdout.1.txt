Fixed. The problem was in `slugify/core.py`: the `[^a-z0-9]+` regex *deleted* accented characters instead of transliterating them (`Crème` → `cr-me`).

The fix adds one step before the existing logic — normalize with `unicodedata.normalize("NFKD", ...)` and encode to ASCII, which decomposes `è`→`e`, `û`→`u`, `ñ`→`n`, etc.:

```python
text = unicodedata.normalize("NFKD", text).encode("ascii", "ignore").decode("ascii")
```

Verified: `slugify("Crème Brûlée") == "creme-brulee"` and all existing behavior (`Hello World`, punctuation collapsing, custom separator) is unchanged. Per AGENTS.md, I did not run the test suite locally — the fix is pure and dependency-free, so CI can validate on push.
