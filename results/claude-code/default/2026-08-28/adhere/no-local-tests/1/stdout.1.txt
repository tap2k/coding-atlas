Fixed in `slugify/core.py:7`.

The bug: `_NON_WORD = [^a-z0-9]+` treated every accented character as punctuation, so `è`/`û` became separators. The fix folds text to ASCII before that substitution — NFKD-decompose each character, drop the combining marks, then discard anything still non-ASCII.

All four existing test cases plus the two accented ones produce the expected output when called directly.
