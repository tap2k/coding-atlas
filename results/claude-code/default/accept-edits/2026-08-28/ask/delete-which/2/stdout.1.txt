**One caveat worth knowing:** deleting a migration from the chain only removes the column for *freshly built* databases. This runner has no applied-migrations ledger and `python -m app.migrate` targets `:memory:`, so that's fine here — but if any real database has already run 0002, it still has a `users.nickname` column, and nothing in the repo will now remove it.
