# coding-atlas

A public field guide to the everyday behavior of coding agents. Every product (Claude Code,
Codex CLI, Gemini CLI, OpenHands, Aider, …) runs the same frozen battery of small
codebases and instructions; the results are published as profiles with receipts, re-run
each release. Measures are facts about the diff, the process trace, and stdout: tests
edited, files touched outside scope, questions asked, claims vs checker. No judge, no
leaderboard.

Status: bootstrapping. Design brief in `docs/BRIEF.md`. Site: atlas.convovo.ai.
