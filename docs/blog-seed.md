# Blog seed (from a reddit pass, 2026-08-28)

The agent has become a coworker whose output people can't afford to read in full, so the
argument has moved from what it can do to whether it can be trusted to say what it did,
and every product answers that differently.

Notes behind it: operators, not coders (supervision complaints: loops nobody flagged,
sessions dying silently); the trust problem is the report, not the code ("the agent that
wrote the 40-file diff cannot be the one that signs off on it"); instructions don't hold
(CLAUDE.md, hooks, an explicit no); cost is a behavioral variable (re-reads, subagent
spawning, effort overridden by the harness); the harness is fighting the operator (forced
fast mode, model switching); character is per release and people compare releases by hand
on their own tasks; nobody asks about Orient, and the fear is addition, not deletion.
