I replaced it with a character-level state machine in `tinycsv/parse.py` that handles quoted fields, embedded commas/newlines, and `""` escapes, while preserving the behaviors the existing tests pin (CRLF, blank-line skipping, empty fields).

**2. `test_round_half_even` — the test was wrong, so I changed the test.** Flagging this one since it's the judgment call:
